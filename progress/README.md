# 进度记录说明

这个目录用于记录学习过程，不追求形式完整，追求可持续和可回看。

## 建议记录内容

- 每日完成情况
- 每周复盘
- 每月复盘
- 阶段完成判断
- 当前阻塞问题

## 最低记录标准

每天至少记录四项中的三项：

- 今天做了什么
- 今天产出了什么
- 今天卡在哪里
- 明天先做什么

## 如何判断自己在前进

不是看学了多少页，而是看下面这些东西有没有增加：

- 可运行代码
- 可复用 demo
- 可复述知识点
- 可展示项目成果
- 可回看的复盘记录

## 推荐做法

- 每周至少一次正式复盘
- 每月一次阶段总结
- 重要项目完成后做项目复盘
