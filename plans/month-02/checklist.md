# 第 2 个月验收清单

月末时逐项检查。未通过的项，优先补齐，不要急着进入下个月。

## 分层与工程设计

- [ ] 能解释 handler、service、repository 各层职责
- [ ] 能说清依赖方向：上层依赖下层，下层不依赖上层
- [ ] 能用 interface 做依赖倒置
- [ ] 项目结构具备可读性和可扩展性

## 配置与日志

- [ ] 能从配置文件读取服务端口、数据库地址等参数
- [ ] 能使用结构化日志输出请求信息和错误信息
- [ ] 知道为什么不建议用 `fmt.Println` 做日志
- [ ] 能解释 JSON 格式日志的好处

## 数据库能力

- [ ] 能用 `database/sql` 或 `sqlx` 完成基础 CRUD
- [ ] 能解释连接池的作用和基本配置
- [ ] 能正确使用事务处理多步操作
- [ ] 能处理数据库错误并返回合理 HTTP 响应
- [ ] 能写 SQL migration 或手动建表

## 中间件与 Context

- [ ] 能写日志中间件记录请求耗时
- [ ] 能写 panic recovery 中间件
- [ ] 能解释 `context.Context` 的传递和取消机制
- [ ] 能用 context 设置请求超时
- [ ] 知道什么时候该往 context 里存值，什么时候不该

## 错误码与参数校验

- [ ] 有统一的错误返回结构
- [ ] 能区分客户端错误和服务端错误
- [ ] 能对请求参数做基本校验
- [ ] 能返回有意义的错误信息

## 项目能力

- [ ] Blog API 项目可完整运行
- [ ] 项目具备分层结构
- [ ] 能说清每层的实现方式和设计取舍
- [ ] 能指出当前项目的已知不足和改进方向

## 测试与复盘

- [ ] 写过至少 5 个有效测试用例
- [ ] 测试覆盖了 service 层和 handler 层
- [ ] 做过至少 1 次周复盘
