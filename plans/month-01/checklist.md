# 第 1 个月验收清单

月末时逐项检查。未通过的项，优先补齐，不要急着进入下个月。

## 基础能力

- [ ] 知道如何创建和运行一个 Go module
- [ ] 能独立写基础控制流和函数
- [ ] 能解释 struct、method、interface 的基本用法
- [ ] 能正确处理常见 error 返回
- [ ] 能解释值传递和指针传递的差异

## 后端基础能力

- [ ] 能用标准库写最小 HTTP 服务
- [ ] 能处理 JSON 请求和响应
- [ ] 能返回合理的 HTTP status code
- [ ] 能完成基础 CRUD 接口

## 项目能力

- [ ] Todo API 项目可运行
- [ ] 项目结构具备最小可维护性
- [ ] 能说清楚每层职责
- [ ] 能指出当前项目的已知不足

## 测试与复盘

- [ ] 写过至少 3 到 5 个测试用例
- [ ] 做过至少 1 次周复盘
- [ ] 做过至少 1 次月复盘
- [ ] 记录过至少 5 个常见坑或错误模式

## 就业导向检查

- [ ] 能向 Java 面试背景的人解释为什么你在学 Go
- [ ] 能说明 Java 到 Go 的迁移差异
- [ ] 能把第 1 个月项目作为学习成果进行介绍
- [ ] 打开仓库后，能在 3 分钟内知道今天要做什么
