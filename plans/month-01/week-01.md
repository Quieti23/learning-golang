# Week 1：环境、语法、最小 Go 手感

## 本周目标

- 安装并确认 Go 开发环境
- 理解 module、package、main、func 的基本关系
- 熟悉变量、控制流、struct、method、error 的基本写法
- 开始形成“用 demo 验证”的学习习惯

## 本周交付

- `demos/month-01/` 中新增多个基础示例
- `exercises/month-01/` 中完成基础练习
- 写一份周复盘

## 建议日程

### Day 1

- 安装 Go，确认 `go version`
- 理解 `go mod init`、`go run`、`go test`
- 建一个 `hello-go` demo
- 输出：能独立跑通第一个 Go 程序

### Day 2

- 学变量、常量、基本类型、if、for、switch
- 写 3 个小 demo
- 输出：能空手写出基本控制流

### Day 3

- 学函数、多返回值、error
- 对比 Java exception 和 Go error
- 输出：写一个返回结果和错误的小函数集

### Day 4

- 学 struct、method、receiver
- 输出：写一个 `User` 或 `Task` 的基础模型 demo

### Day 5

- 学 package 拆分和基础文件组织
- 输出：把前几天的一个 demo 拆成两个 package

### Day 6

- 整理本周 demo 和练习
- 补不会的点
- 输出：查缺补漏，不追新知识

### Day 7

- 做周复盘
- 判断是否满足进入 Week 2 的条件

## 本周进入条件

满足以下条件再进入 Week 2：

- 能解释 `main`、package、module 的关系
- 能独立写函数并返回错误
- 能写一个带 method 的 struct 示例
- 知道 Go 为什么不鼓励过早抽象

## 本周风险提醒

- 不要一开始追框架
- 不要为目录设计花太多时间
- 不要把“看懂示例”当成学会
